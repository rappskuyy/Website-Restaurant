# 🍽️ Restaurant Website (React)

Website restoran sederhana yang dibuat menggunakan **React** untuk menampilkan menu makanan, informasi restoran, dan galeri dengan tampilan modern serta interaktif.

## ✨ Fitur

* Menampilkan daftar **menu makanan dan minuman**
* Halaman **informasi restoran**
* **Galeri foto** restoran
* Tampilan **responsive** untuk desktop dan mobile

## 🛠️ Teknologi yang Digunakan

* React
* JavaScript
* CSS
* Vite

## 📸 Preview

Website ini menampilkan halaman utama restoran dengan daftar menu, galeri, dan informasi tentang restoran.
